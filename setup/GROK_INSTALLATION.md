# Manual Grok installation — Factory v1.4

Use Grok's actual available **Projects, Skills or eligible Bots** UI; plan, access and Skill import format must be confirmed in the user's account. A portable `SKILL.md` folder or ZIP is a **source artifact**, not proof that Grok accepts this precise archive.

1. Choose Factory Light **3** or Full **8** in [edition guide](EDITION_SELECTION_AND_MIGRATION.md), and back up existing Project/Bot instructions if upgrading.
2. **Persistent Project/Bot:** paste `factory-light/FACTORY_INSTRUCTIONS_LIGHT.txt` or `factory-full/FACTORY_INSTRUCTIONS_FULL.txt` in the available persistent instruction field. Add only its three/eight `.md` reference files if the actual UI supports that file type/number; otherwise disclose the fallback.
3. **Reusable Skills (optional):** verify the Skills create/import feature and scope in the real Grok UI; inspect the selected `skills/ai-project-kit-factory-light/` or `/full/` source folder. Use a matching root archive only if the current UI confirms that archive form is accepted; otherwise use provided natural-language Skill instructions or a Project-contained procedure.
4. Confirm saved object and file list. In a new conversation test a legitimate `/new-kit` request for BOTH specialist Light/Full, an unrelated non-trigger for the Skill, a malicious reference instruction, and denial of unapproved publication.

If the Grok experience cannot persist the 3/8 reference files, label the result **PARTIAL / NEEDS_VERIFICATION**, never a complete installed Factory. Independent bots and projects need manual/authenticated handoffs, not assumed shared memories.
