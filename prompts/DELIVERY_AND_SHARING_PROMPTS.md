# Distribution, sharing and setup prompts

These are **generic prompts**, not a sample generated kit. The Factory should personalize them to each user's actual project and allowed tools.

## Ask for a package

> `/deliver package` — Create a self-contained, GitHub-ready ZIP for the kit you just generated. Include `README.md` using the Factory's generated-kit README template, `AI_SETUP_PROMPT.md`, `KIT_MANIFEST.md`, Light and Full role folders, optimized operating prompts, platform instructions, installation checklist, and validation records. Do not imply the repository has been published. If ZIP creation is impossible in this environment, deliver complete labeled copy/paste files instead.

## Ask for current-tool installation

> `/deliver install` — Walk through setup in the AI platform I'm using, or configure each role directly only if you have actual authenticated write permission and my explicit approval. Distinguish AI-generated files from persistent objects. Give me one practical checkpoint at a time and run fresh-context tests. Record a deployment receipt.

## Ask for both

> `/deliver both` — Package both editions first (or supply named file blocks if file creation isn't available), then guide or perform authorized current-platform installation. Do not claim GitHub publication without evidence.

## Share the Factory itself

> Open https://github.com/robotros/AI-project-kit-factory and read START_HERE.md plus the relevant Light or Full Factory instruction and knowledge files. If you can't access all files, ask me to upload them. Help install the Factory using authorized tools or a guided walkthrough. Then create a new project kit and offer two delivery choices: GitHub-ready ZIP or installation in the current AI tool (allow both).

## Share a generated kit

> Install the AI kit in [PUBLISHED_KIT_REPOSITORY_URL]. Read its README.md and AI_SETUP_PROMPT.md first, then the exact instruction and Markdown reference files. If the URL isn't live or inaccessible, request the ZIP/files instead. Configure directly only with verified tools and consent; otherwise guide setup on this platform and run documented checks for each specialist role.

## Make a GitHub setup link after publication

> After I publish the generated kit, check the actual repository URL and default branch. Provide a verified link to its README and AI_SETUP_PROMPT.md, and a compact copy/paste prompt I can share. Never invent a live link from a ZIP filename.
