# Installation & acceptance checklist — [KIT_TITLE]

- [ ] Confirm destination AI platform, account constraints, and whether each role should be persistent.
- [ ] Confirm which edition is being installed (Light / Full).
- [ ] Confirm count and names of every project/agent/skill/Gem/bot to create.
- [ ] If modifying an account directly, identify authenticated write tools and receive explicit approval for each external action.
- [ ] For each role, create destination object (or documented dedicated-chat fallback).
- [ ] Paste the correct `PROJECT_INSTRUCTIONS.txt` into the supported instructions field.
- [ ] Attach exactly the chosen role's three Light or eight Full `.md` files when permitted; document any changed packaging if upload limits require it.
- [ ] Run a normal-case kickoff and a missing-information/refusal-or-approval test in a fresh context.
- [ ] For multi-role workflows, test a real handoff packet and verify who transports it.
- [ ] Record created URLs/object IDs only when observed; record user-confirmation separately from authenticated readback.
- [ ] Finish the deployment receipt with a clear GENERATED_ONLY / USER_CONFIRMED / TOOL_VERIFIED / OPERATIONALLY_TESTED status as appropriate.
- [ ] List unresolved gaps and security/privacy considerations.
