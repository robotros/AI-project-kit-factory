## New since v1.4.1

- /new-kit asks the generated kit owner to choose its license. MIT, Apache-2.0, GPL-3.0, Creative Commons where suitable, proprietary/private, or undecided are supported; this Factory's MIT license never automatically transfers.
- Offer optional GitHub repository social preview image (1280×640, verified <1 MB) and tailored code of conduct, contributing guide, security policy, issue and pull-request templates. These do not count toward Project knowledge files.
- AI-guided setup defaults to the public `https://github.com/robotros/AI-project-kit-factory` repository when no ZIP was attached; it requests exact inaccessible files only if needed.
- Rebuild the distinct Light (3 knowledge files) and Full (8 files) Factory installers and four separate Claude-wrapped/root Skill ZIPs. Both Factory editions generate **both specialist Light and specialist Full for each role**.
- Update release checksums, platform instructions, manifest and validation, while preserving explicit approval and no-autonomous-publishing rules.
