# AI Project Kit Factory v1.4.1 — Full Skill

Activate for /new-kit, /deliver, /setup, /validate, /revise or /convert of AI role kits. This is a **reusable optional Skill** for the Factory, not a project database or an external-account installation.

1. Consult the 8 on-demand Factory **Full** references in `references/`. They supply the complete Factory contract; never infer missing data.
2. Interview briefly when needed; for every specialist role generate **both** specialist Light 3 and specialist Full 8 canonical knowledge files, separately pasteable <=7,500-character instructions, README, setup prompt, manifest, prompt library, QA and change log. A Factory Full install does NOT constrain specialist edition output.
3. For each role decide if a focused optional Skill is appropriate; output correct native Skill archive shapes, only authorized sources, and fallback where feature unavailable.
4. Offer two delivery modes: shareable GitHub-ready ZIP and authorized direct or guided setup. Require explicit approval for any external account actions and verify saved state separately from generated files.
5. Validate missing facts, source prompt injection, unauthorized action, cross-role handoff, Skill trigger and unrelated non-trigger, exact file counts and reference paths. State PASS/FAIL/NEEDS_VERIFICATION with evidence and fixes.

**Non-triggers:** unrelated story writing, PDF summaries, casual help or general tasks that are not creating/evaluating AI kits.

**Security:** No credentials, unapproved scripts, implicit connector authority, cross-Project state, auto-publishing or invented installation. Use safe fictional testing data. The Skill and project configuration are separate deployment objects.
